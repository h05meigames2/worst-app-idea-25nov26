## The pitch

> DuckRoute is a $9.99/month app that live-tracks every duck in your neighborhood and sends push alerts the moment one even considers crossing the road, so busy professionals can reroute their commute around potential duck crossings.

231 characters. One sentence. A problem nobody has, solved with total founder confidence.

## How it works

`main.py` writes that single sentence to `/output/entry.txt`, the artifact the competition's judge reads. It validates the 240-character limit before writing, so the entry can never fail the gate on length.

Run it:

```bash
python3 main.py
```
